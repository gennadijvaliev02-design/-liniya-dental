# Линия

Одностраничный фронтенд-сайт стоматологической клиники. Проект не требует сборки: HTML, CSS и JavaScript находятся в `index.html`.

## Локальный запуск

Открывайте сайт через локальный HTTP-сервер, чтобы браузер корректно воспроизводил видео:

```bash
python3 -m http.server 8000
```

После запуска откройте `http://localhost:8000`.

## Публикация на GitHub Pages

1. Загрузите содержимое этой папки в корень репозитория.
2. В настройках репозитория откройте **Settings → Pages**.
3. Выберите **Deploy from a branch**, ветку `main` и каталог `/ (root)`.
4. После публикации проверьте мобильное и десктопное видео по HTTPS-адресу.

Все пути к изображениям и видео относительные и совместимы с публикацией в подпапке GitHub Pages.

## Важно

Форма записи работает как фронтенд-демонстрация и не отправляет данные на сервер. Для реальных заявок потребуется отдельная интеграция с CRM, почтой или другим обработчиком.
